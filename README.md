# bim-all-doors

Gecleanter Fork der "BIM All Doors" von [Frank Beister / Dormakaba](https://github.com/dormakaba/bim-all-doors).  
Basiert auf der dort aktuell (2026-05-12) letzten Version v1.93.

> [!WARNING]  
> Diese Version wurde kräftig bereinigt und ist deshalb ___NICHT___ Upstream kompatibel.  
> Dafür benötigt man jetzt zum Bearbeiten allerdings auch kein proprietäres Tool ("_Nucleus_") mehr, sondern kann ganz normal mit dem `LPXML_Converter` arbeiten.
